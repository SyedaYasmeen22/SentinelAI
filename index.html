Architecture

Deep Learning Stack

Built on battle-tested neural architectures with ImageNet pre-training and state-of-the-art transfer learning.

ResNet-50

50-layer deep residual network with skip connections eliminating vanishing gradients. Achieves 76% top-1 on ImageNet with ~25M parameters and a 2048-d feature vector at the global average pooling layer.

Backbone

COCO-SSD Detector

Single Shot MultiBox Detector trained on the 80-class COCO dataset. Detects people, vehicles, animals, and everyday objects in a single network forward pass — real-time capable on CPU.

Detector

CIFAR-10 Dataset

60,000 labelled 32×32 RGB images across 10 classes: airplane, automobile, bird, cat, deer, dog, frog, horse, ship, truck. Primary benchmark for training and evaluating image classification models.

Dataset

Transfer Learning

Freeze ImageNet-trained ResNet-50 weights and fine-tune only the classification head. Dramatically reduces training data requirements and achieves ~82% CIFAR-10 accuracy without training from scratch.

Strategy

TensorFlow / Keras

End-to-end ML platform for model definition, training, evaluation, and browser deployment. TF.js enables in-browser GPU-accelerated inference via WebGL — no server required for this demo.

Framework

Regularisation Techniques

Batch normalisation stabilises activations between layers. Dropout (p = 0.4) randomly deactivates neurons during training. Global average pooling reduces spatial feature maps to compact vectors.

Roadmap

Future Directions

The path from academic prototype to production-grade intelligent surveillance infrastructure.

01

Edge AI Deployment

Quantise and prune the ResNet-50 model for NVIDIA Jetson Nano and Raspberry Pi 5 deployment, enabling offline, low-latency inference directly at the camera — no cloud dependency.

Near-term · 2025 – 2026
02

Real-Time RTSP Streams

Extend the pipeline to ingest live RTSP/RTMP video at 25+ FPS using asynchronous processing and TensorRT-optimised inference on CUDA-enabled GPUs.

Near-term · 2025 – 2026
03

Temporal Action Recognition

Add LSTM or 3D-CNN layers to model temporal dynamics — detecting suspicious activities, fights, or falls across video sequences rather than individual frames.

Mid-term · 2026 – 2027
04

Multi-Camera Tracking

Track individuals and objects across multiple non-overlapping cameras using re-identification networks and spatial-temporal graph neural networks.

Mid-term · 2026 – 2027
05

Federated Learning

Train models across distributed surveillance nodes without centralising sensitive footage — improving model generalisation while maintaining data privacy compliance (GDPR, PDPA).

Long-term · 2027+
06

Multimodal Intelligence

Fuse visual CNN features with audio analysis, thermal imaging, and LiDAR point clouds for comprehensive all-weather, all-lighting situational awareness.
